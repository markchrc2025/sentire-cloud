# Sentire Cloud offer (draft for the owner)

| Tier | What the client gets | Runs on |
|---|---|---|
| Shared | their own site inside a Sentire product (one database each), backups, updates, monitoring | Sentire's shared servers (Dokploy) |
| Dedicated | a server pair for one client (the Ledger Enterprise tier) | servers in Sentire's account |
| PH-hosted | the same, on Philippine servers rented from ALC Hosting (MNL, MNL2, CRK) | ALC Hosting, managed by Sentire |

Included in every tier: daily encrypted backups to object storage, a monthly restore test,
uptime checks (this console), security updates through pinned Sentire Framework releases.
Prices: not set here. They come from each product's price list (Ledger: Solo to Enterprise)
and from the ALC quote (CLD-2, CLD-3).
